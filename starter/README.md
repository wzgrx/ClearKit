# 【模块】

【宿主】的 LSPosed 模块：去广告和体验增强。

- 支持：【宿主】（`com.example.host`）；内置适配的版本见 `core/model/.../HostBuild.kt`，其它版本打开模块 App 后在手机上自动适配。
- 需要：Android 9 及以上、LSPosed（API 102）；在 LSPosed 里启用模块并勾选【宿主】，然后重开【宿主】。
- 开发：见 [AGENTS.md](AGENTS.md)；家族规范和工具在 [ClearKit](https://github.com/wzgrx/ClearKit)。
