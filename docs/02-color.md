# 02 · 强调色

## 原则

- **取宿主品牌色的邻近色，不用原色**：让人一眼联想到宿主，但不像官方 App。
  - 哔哩净界：哔哩哔哩是粉色，模块界面用**青绿**（反差更大，强调“这是另一个东西”）；图标主体用粉色玻璃。
  - 红薯净界：小红书是正红 `#FF2442`，模块用**红薯的玫红**（往紫一点），不用小红书的红。
- 只定**一个种子色**，浅色、深色两套界面色从它推出来，不要每个颜色手调。
- 强调色只用在：选中状态、主按钮、开关打开、“改了 N 处”这类提示、进度。大面积背景、正文不用强调色。

## 从种子色推两套颜色

界面配色的结构所有模块一样（参考 BiliClear `app/.../ui/theme`、ShuClear `Rb.colors`），只有这几项从种子色算：

| 名字 | 浅色模式 | 深色模式 | 用在 |
|---|---|---|---|
| accent | 种子色 | 种子色提亮 10–15% | 主按钮、开关、选中 |
| onAccent | 白 | 深色底（`#1A1A1A`） | 强调色上的文字 |
| accentSoft | 种子色 12% 叠在白上 | 种子色 22% 叠在深底上 | 浅强调底（标签、选中卡片） |
| accentInk | 种子色压暗到对比度 ≥ 4.5 | 种子色提亮到对比度 ≥ 4.5 | 浅底上的强调文字 |

检查：`accentInk` 在 `surface` 上、`onAccent` 在 `accent` 上，对比度都要 ≥ 4.5（WCAG AA）。

## 图标颜色和界面颜色的关系

图标不一定用界面强调色（哔哩净界界面是青绿、图标是粉）。图标颜色按 [03-icon-design.md](03-icon-design.md) 的家族规则：
**暖色主体**（玫红 / 橙 / 粉 / 红，两色渐变）+ **晶透蓝第二面** + **乳白记号**。

## 已用的颜色

| 模块 | 界面种子色 | 图标主体渐变 | 第二面 |
|---|---|---|---|
| 哔哩净界 | 青绿：浅色 `#0B6E69`，深色 `#4FD1C5` | 粉 → 浅粉 | 晶透蓝 |
| 红薯净界 | 玫红：`#D6336C`（浅深色同一个） | `#FF2D6F` → `#FF9A3D` | `#3E8BFF` → `#A8E2FF` |

新模块的主体色避开已用的，在暖色里选：例如黄橙、珊瑚、品红。
