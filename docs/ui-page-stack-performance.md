# 页面栈离屏测量

深层页面组合和 ViewModel 要保留，方便返回时恢复状态；已经完全离屏的页不必继续跟随根布局尺寸重测。PageStack 在父约束宽高有界、placed 为 false 时，只保留容器尺寸，不测量内容。进入返回手势或转场的相邻页继续正常测量和摆放，未约束场景沿用原路径。

本次不改变公共参数、动效、圆角或家族风格。红薯净界中新增真实 Compose 页面栈的六层交互回归，检查根高度改变时较深四层不参与测量、组合实例保留、返回原页面可见；ClearKit Compose Lint 同步通过。其它模块使用同一源码时也要保留自己的发布门禁，库源码通过不能替代各模块的实机验收。
