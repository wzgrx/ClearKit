# 03 · 图标设计（画什么）

这一篇讲**设计思路**：一个新模块的图标里放什么、怎么摆。怎么用 Blender 出图见 [04-icon-pipeline.md](04-icon-pipeline.md)。

![家族图标](../examples/family/family.png)

## 家族的四个共同点（每个图标都要有）

1. **暖色玻璃主体**：图标里最大、最靠前的东西，玫红 / 橙 / 粉 / 红的两色渐变，像彩色琉璃，透光、有清漆高光。
2. **晶透蓝的第二面**：主体后面斜放一块蓝色玻璃（卡片、屏幕、页面），和暖色主体形成冷暖对比，也让图标有前后层次。
3. **一个乳白记号**：压在主体正面，不透明的乳白色，代表“净”。四角星闪光、播放键、对勾这类简单形状，**只能有一个**。
4. **霓虹外发光**：整个图标外面一圈柔光，深色底上尤其明显。

再加两条：**透明背景**（底色由系统的自适应图标背景提供），**不写字**（图标里不放汉字和字母）。

## 怎么把图标和宿主联系起来

**只借意象，不用宿主的 logo 和文字。**

| 来源 | 例子 |
|---|---|
| 宿主的昵称变成实物 | 小红书 → “薯” → 一颗红薯 |
| 宿主的标志性物件 | 哔哩哔哩 → 带天线的小电视 |
| 宿主的内容形态 | 小红书 → 竖放的笔记卡（标题行 + 正文行）；视频 App → 播放键、进度条；阅读 → 书页 |

一般是**一个昵称实物做主体 + 一个内容形态做第二面**：红薯（主体）+ 笔记卡（第二面）+ 四角星（记号）。

不要：

- 照抄宿主图标的轮廓、配色组合、字标（例如小红书的红底白字、哔哩哔哩的粉色小电视 logo 原样）。
- 堆太多东西：主体 + 第二面 + 记号 + 最多一个小装饰（叶子、天线）。东西多了在 48dp 上糊成一团。

## 构图

坐标：镜头在前方正对图标，X 向右、Z 向上、Y 越小越靠前（离镜头越近）。

```
          ┌──────────┐   第二面：偏右上，往后（y≈+1.2），绕 Y 轴转 -8°~-10°
          │ ▬▬▬▬     │
          │ ▬▬▬▬▬▬   │
   ╭──────┴────╮     │
   │  主体  ✦  │─────┘   主体：偏左下，最靠前（y≈0），可以斜放 -20°~-25°
   ╰───────────╯         记号：压在主体正面（y≈-1.1），居主体中间
```

- **主体偏左下、第二面偏右上**，两者有重叠，形成对角线。
- 记号在主体的视觉中心，比主体小很多（主体宽的 1/4 左右）。
- 整体用 `root.location` 平移居中；出图后 `report.txt` 的安全区检查必须通过（不透明的部分在圆形遮罩里）。
- 小装饰（叶子、茎、天线）放在主体的“头”上，往右上伸，把视线引向第二面。

## 颜色

| 部分 | 怎么选 | 例子（红薯净界） |
|---|---|---|
| 主体 | 暖色两色渐变，左深右浅或左冷右暖；`glow` 0.4–0.6、`transmission` 0.5–0.65 | `#FF2D6F` → `#FF9A3D` |
| 第二面 | 蓝色两色渐变，深蓝到天蓝；更透（`transmission` 0.75–0.85）、自发光弱一些 | `#3E8BFF` → `#A8E2FF` |
| 记号 | 乳白，不用改 | `milk` |
| 小装饰 | 绿色系（叶子、茎） | `#33D18C` |
| 边缘光 `rim` | 每个玻璃材质配一个，取它渐变浅色那端再提亮 | 主体 `#FFE0C2`、第二面 `#E2F4FF` |

## 设计流程

1. 写三个候选意象组合（主体 / 第二面 / 记号），给维护者选。
2. 选定后复制 `blender/specs/template.json`，先用最简单的形状（`egg`、`slab`、`star`）摆出构图，`--quick` 出图看。
3. 调形状：主体用 `egg` 的参数变形（见 04 的形状说明），复杂轮廓画 SVG 用 `svg` 形状。
4. 调颜色：只改 materials 里的颜色，参数保持家族默认值。
5. 看 `preview.png` 的四种桌面效果；在 48dp 大小下（手机桌面实际大小）还能认出是什么。
6. 出正式图，放进模块的 `docs/brand/`，按 04 接进 Android 项目。
7. 画主题图标线稿（单色），见 04 的“主题图标”。

## 评审时看什么

见 [checklists/icon-review.md](checklists/icon-review.md)。最重要的三条：

- 缩到 48 像素还认得出主体是什么。
- 浅色、深色底上都好看，深色底上外发光不发脏。
- 和家族另外两个摆在一起像一家，单独看又能认出是哪个宿主。
