# 01 · 起名字

## 规则

**中文名 = 宿主昵称（两个字）+ 净界**　　**英文名 = 宿主英文昵称 + Clear**

| 宿主 | 中文名 | 英文名 / 仓库名 | 昵称从哪来 |
|---|---|---|---|
| 哔哩哔哩 | 哔哩净界 | BiliClear | 用户和官方都说“哔哩” |
| 小红书 | 红薯净界 | ShuClear | 小红书用户自称“薯”，“红薯”是常见昵称 |

“净界”是家族后缀：“净”是去掉不想要的东西，“界”是有边界、你自己说了算的空间。

## 怎么找昵称

按顺序试，用第一个合适的：

1. **用户圈里的昵称、黑话**：小红书 → 薯、红薯；哔哩哔哩 → 哔哩、B 站（“B站净界”太长，取“哔哩”）。
2. **名字里最有特点的两个字**：例如某某视频 → 取能代表它的两个字。
3. **App 的形象、吉祥物、标志性物件**：小电视、红薯、果子、胶片。

要求：

- 两个字，读起来顺，和“净界”连读不拗口（念三遍试试）。
- **不能用宿主的完整商标名**（不叫“小红书净界”“哔哩哔哩净界”），免得像官方出品，也避开商标问题。
- 不和家族里已有的重名或太像。
- 英文名用拼音或通用英文词，首字母大写，后面直接接 `Clear`，不加空格、不加连字符。

## 改名只改显示名

已经发布过的模块改名时（例如“红薯助手”→“红薯净界”）：

- **包名不改**，签名不改，用户能直接覆盖安装，设置和数据都保留。
- 改：App 显示名、模块描述、界面和宿主里的文案、README、GitHub 仓库名（旧地址会自动跳转）。
- **存储目录沿用旧名**（例如 `Pictures/红薯助手/`）：改了会让新下载换目录，“跳过已下载”这类功能失效。
- 版本说明、更新日志里的历史记录不改。

## 起名时给维护者的提案格式

```
候选：红薯净界（ShuClear）
昵称来源：小红书用户自称“薯”，社区常说“红薯”
读音：hóng shǔ jìng jiè，连读顺
和家族的关系：同“哔哩净界”格式
不用：小红书净界（商标全名）、书净界（不知所云）
```

起名要维护者拍板，AI 只出候选和理由，不要自己定。
